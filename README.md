## 🗂️ How to read each project folder

Every project folder follows the same structure once it's live:

- **`README.md`** — the problem, the decisions made, and a "what I'd do differently" section
- **Working code / artifact** — the actual thing that was built, not just a writeup
- **Design doc or memo** — the PM-level reasoning, sized to the project (a paragraph for smaller builds, a full memo for Projects 6–8)

Each project maps to a phase in the **[build sequence](./LEARNING.md)** — that's where to look for the resources used and the reasoning behind why each phase came before the next.
